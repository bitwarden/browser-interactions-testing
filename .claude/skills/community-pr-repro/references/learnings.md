# Learnings

Read before every run. Append one dated line per lesson that cost a retry or changed an approach. Promote a lesson into SKILL.md once it has held for two PRs.

Format: `- YYYY-MM-DD (#<PR>) <what happened> -> <what to do instead>`

- 2026-11-12 (#23906, #24489) Fork PRs leave `build-browser.yml` at `action_required`, so there is no Chrome artifact to download -> build locally with `gh pr checkout` in `$BIT/clients`.
- 2026-11-12 Popup autofill needs a fresh page at `popup/index.html#/tabs/vault?senderTabId=<formTabId>` (param after the hash); a hash change on a loaded popup does not re-init it.
- 2026-11-12 Page-load autofill needs both the global toggle and the per-login default select; visiting `#/autofill` writes the default to `false`, so set the select explicitly.
- 2026-11-12 Inserting entries mid-array in `testPages`/`pageCiphers` shifts index-derived item names -> append, or run `npm run seed:vault:ciphers:refresh`.
- 2026-11-12 Card expiration fills as `12/25`; identity full name fills as one value (`John M Smith`) in a single `#full-name` field.
- 2026-11-12 (#23906) An inline `<script>` in a Docusaurus `.md` page is inserted into the DOM but React never executes it -> use `.mdx` and import a React component that wires behavior in `useEffect`. Don't try to ship bug-reproducing JS in a plain `.md` page.
- 2026-11-12 (#23906) New identity pattern page URL `address-na-dynamic-state` collides with the seeded `address-na` identity cipher under `UriMatchType.StartsWith`, seeding two matching ciphers for the new URL -> pick a slug that is not a prefix extension of an existing cipher URL (renamed to `dynamic-state-address`).
- 2026-11-12 (#23906) A `gh pr checkout` of an older PR branch (many commits behind main) builds against BIT's current-main `node_modules` and the extension build fails with cross-module TS errors -> run `npm ci` in `$BIT/clients` after checkout to install the PR's lockfile deps deterministically, then `npm ci` again after `git switch main` to restore. (Originally written as `npm install`; corrected 2026-11-13 - `npm ci` is deterministic, faster, and won't mutate `package-lock.json`.)
- 2026-11-12 (#23906) `background.evaluate(() => chrome.tabs.sendMessage(...))` only works because BIT's fixture holds a service-worker handle. Via Playwright MCP that handle is not exposed, so `chrome.tabs.sendMessage` from the popup tab appears to no-op. The actual gate is `autofill-orchestrator.commit` requiring the target tab to be the active/foreground tab at fill time. For MCP-driven hand repros against the message-autofill path: `chrome.scripting.executeScript` the content bootstrap files into the test tab, send `startAutofillMonitors`, `chrome.tabs.update(testTabId, { active: true })`, then send `{ command: "collectPageDetails", tab, sender: "autofill_identity" }`.
- 2026-11-13 (#23906) MCP config records every Playwright context start-to-close, so exploration bloats `manual-main.webm` (saw 31M / 3min for ~15s of real repro). Do setup in a throw-away session, close, delete `repro/_pending-videos/*.webm`, then relaunch for the final tight pass. Covered in Step 3 item 5.
- 2026-11-13 (#23906) Classifier correctly blocks any attempt to route `VAULT_PASSWORD` into the Playwright MCP sandbox (echoing to stdout, writing to a temp file, spinning a loopback server all denied). The MCP sandbox has no `require`/`import`/`process`/`fetch file://`. In the two-pass recording flow this isn't a blocker — unlock interactively once per pass. Don't argue with the classifier; ask the user to unlock.
- 2026-11-13 (#23906) `cd $dir && git switch $branch` in a Bash call only sticks for subsequent calls if the persisted cwd actually lands in `$dir`. Absolute-path `cd`s during the session can silently move cwd away, so a later relative `cd test-site` may be a no-op, leaving the branch on whatever the current working directory's repo is. Before rebuilding test-site or BIT, verify with `git -C $dir branch --show-current`.
